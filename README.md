# Animated Analytics Dashboard

A modern, fully responsive **analytics dashboard** built using **HTML**, **CSS**, and **JavaScript**.  
This project includes dynamic charts, real‑time stats, a smooth UI, and a built‑in **dark/light theme toggle**.

---

## Live Demo

**https://sherin-live-data-dashboard.netlify.app/**

## Project Overview

This enhanced dashboard provides:

- **Dynamic SVG line charts** with glow effects
- **Auto-updating statistics** every 2 seconds
- **Dark/Light theme toggle**
- Modern UI with card hover effects
- Fully responsive grid layout
- Clean separation of concerns — HTML, CSS, JS separated
- Commented, beginner-friendly, customizable code

---

## Features

- Fully responsive dashboard layout
- Smooth glowing chart animations
- Randomized real-time metric updates
- Clean, organized component-based design
- User-friendly theme toggle
- No external chart libraries — built with pure SVG

## Tech Stack

| Technology           | Purpose                            |
